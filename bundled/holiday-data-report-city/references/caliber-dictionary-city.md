## 〇、勾稽关系（Reconciliation · 本技能核心）

> 城市数据不是独立的另一套数字，而是全国 SSOT 的**空间剖面**。勾稽关系确保：城市加总与全国总量在可比口径下闭合，读者既能看"哪里强"，又能信"加总对得上"。

### 0.1 数据拓扑与可加性分类（城市 ⊂ 全国，但分两类勾稽）

> 不同指标家族的"可加性"根本不同，勾稽规则**分两类**：单一闭合等式（Σ城市 + 残差 ≡ 全国总量）对流量型指标在结构上不成立（到访口径天然跨城重复），强行套用会误杀正常数据或逼迫人为压数。

**可加性分类（按指标口径类型）**：

| 类别 | 含义 | 代表指标 | 勾稽方式 |
| --- | --- | --- | --- |
| **可加指标** | 按消费地/属地归属、无跨城重复 | 旅游总花费、商务部社零、离岛免税、酒店 RevPAR/间夜、平台 GMV（平台自身口径） | **闭合勾稽**：Σ城市 + 残差 ≡ 全国 |
| **流量指标** | 到访口径，同一人多城被各计，Σ城市 ≥ 全国（去重）为结构性常态 | 出游人次/接待游客量、跨区域人员流动量、铁/民/水客运量、地铁客流、景区/商圈客流人次 | **上限勾稽**：呈现倍数，不要求闭合 |

```
可加指标勾稽等式： Σ_可见城市 M + 其他/未披露 M ≡ 全国总量 M   （同口径、同口径版本、同窗口、同天数）
流量指标勾稽等式： Σ_可见城市 M ÷ 全国总量 M = 倍数（≥1，跨城重复系数，通常 1.5–2.5×）
```

### 0.2 勾稽五铁律

1. **同口径才可比**：城市与全国勾稽时，两端必须满足「指标口径类型相同 + 口径版本相同 + 统计窗口相同 + 假期天数相同」。任一不同即标 `勾稽状态=口径差异`，不得强行相加。
2. **占比规则分指标家族**：
   - **可加指标**：`占比 = 城市值 ÷ 全国总量 × 100%`，合计应 ≤ 100%（差额为未披露残差）。合计 **> 100% + 容差** 触发 R-CITY-1（疑似重复计算/口径冲突）。
   - **流量指标**：`占比 = 城市值 ÷ 全国总量 × 100%` **可 > 100% 且为正常**（跨城重复）；不要求闭合，改为呈现「倍数 = Σ城市 ÷ 全国」（通常 1.5–2.5×）。倍数 **> 3×**（远超合理跨城重复系数）才触发 R-CITY-1（疑似数据错配/重复计数 bug，非单纯口径）。
   - 占比合计 < 100% 的未披露残差，须在报告中显式列出「其他/未披露」行（测算占位，D 级）。
3. **缺失不臆造**：全国有数、城市无分城市披露时，不得编造各城市值；仅以"其他/未披露"测算行兜底，且 `数据性质=推算`、`可信度=D`、`缺口标记=测算待核`。
4. **城市占比之和即披露覆盖率（仅可加指标）**：报告须给出「已披露城市占比合计」与「未披露残差」，二者之和=100%（口径一致前提下）。覆盖率低（如 < 40%）的指标，城市排名叙事须降级为"局部样本，非全域排名"。流量指标不计算"覆盖率"，而以"披露城市倍数"描述。
5. **排名仅在同口径城市间有效**：跨指标、跨口径的城市混排一律禁止；排名表须注明口径版本与可比城市集合（如"纳入 36 个重点旅游城市，口径版本：重点监测景区接待量"）。

### 0.3 勾稽状态枚举（字段 28 取值）

| 勾稽状态 | 含义 | 处置 |
| --- | --- | --- |
| `已勾稽` | 可加指标：已披露城市加总与全国总量差异 ≤ 容差（默认 ≤5%，或 ≤ 未披露城市合理残差） | 正常呈现占比与排名 |
| `部分勾稽` | 可加指标仅部分城市披露，占比合计 < 100% 且为真实披露残差 | 显式列"其他/未披露"行；排名标"局部样本" |
| `流量非加和` | 流量指标：Σ城市 ≥ 全国为结构性常态（跨城重复），不要求闭合 | 呈现倍数（1.5–2.5× 为正常），占比可 >100%，排名标"到访口径/含重复" |
| `口径差异` | 城市口径与全国口径不可比（如城市含/不含某客群、统计边界不同） | 并列说明，禁止相加；占比标"不可比" |
| `未披露` | 全国有数、无任何分城市披露 | 整指标城市维度标"本期无分城市披露"，不编造 |

### 0.4 容差与告警

- **R-CITY-1（可加指标占比超 100% / 流量指标异常高倍）**：
  - 可加指标：城市加总 > 全国总量 × (100% + 容差) → 阻断，查重复计算/口径冲突；
  - 流量指标：Σ城市 ÷ 全国 > 3×（远超跨城重复系数）→ 阻断，查数据错配/重复计数；正常 1.5–2.5× 不报警，仅标注 `流量非加和`。
- **R-CITY-2（口径漂移）**：城市行与所引全国行「口径版本/统计窗口/天数」不一致 → 标 `口径差异`，不得入占比链。
- **R-CITY-3（幽灵城市）**：城市行无对应全国指标引用（字段 26 为空）→ 阻断，每条城市数据须显式关联全国指标键。
- **R-CITY-4（臆造残差）**：用虚构城市值填满"其他/未披露"而非测算占位 → 违反零虚构，D 级兜底必须 `数据性质=推算`。

## 一、城市维度增量字段（22 字段 + 8 城市增量 = 城市行 30 字段）

> 顺序固定、列名不得删改。前 22 字段同父技能《口径字典》第〇节；后 8 字段为城市增量，仅在 `地域粒度` ≠ `全国` 的记录上填写。

`…（前 22 字段同父技能）… | 地域粒度 | 区域 | 城市层级 | 关联全国指标 | 占全国比重 | 勾稽状态 | 城市排名 | 修订状态`

| # | 字段 | 取值 / 示例 | 说明 | 必填 |
| --- | --- | --- | --- | --- |
| 23 | 地域粒度 | `全国`/`北京`/`成都`/`县域-某某县` | 复用父技能 SSOT 同名治理字段：全国行填 `全国`，城市行填城市/县域**全称**（直辖市/地级市/县域同理）。不另设「城市」列 | 是 |
| 24 | 区域 | `华北`/`华东`/`华南`/`华中`/`西南`/`西北`/`东北` | 七大地理分区，用于区域聚合与区域分布图 | 是 |
| 25 | 城市层级 | `直辖市`/`省会`/`计划单列市`/`地级市`/`县域` | 分层统计与样本代表性声明 | 是 |
| 26 | 关联全国指标 | `总体\|[节假日]出游人次` | 本城市行勾稽到的全国 SSOT 指标键（主题\|数据点），R-CITY-3 校验 | 是 |
| 27 | 占全国比重 | `12.3%`/`_<100%_`/`不可比` | 城市值÷全国总量；口径差异填"不可比" | 是（口径差异除外） |
| 28 | 勾稽状态 | `已勾稽`/`部分勾稽`/`口径差异`/`未披露` | 见 0.3 枚举 | 是 |
| 29 | 城市排名 | `全国第3`/`区域第1`/`_`（样本不足） | 同口径可比城市集合内排序；样本不足标 `_` | 否 |
| 30 | 修订状态 | `初值`/`终值`/`已回溯修订`/`未标注` | 针对本城行及其 `关联全国指标` 的修订状态；全国指标若已回溯修订须重验勾稽（见第五节） | 是（默认 `未标注`） |

**等级标准（继承父技能）**：A 政府公告/官方统计 ｜ B 权威媒体转引机构数据 ｜ C 企业自披露/券商研报/行业机构 ｜ D 弱溯源/推算/预计。城市数据中来自省文旅厅/市文旅局/市监的官方发布，优先按 A/B 定级；携程/同程"城市热度榜"属平台自披露，须标 C 级 + "该平台自身口径，非全市场"。

**强制 D 规则（继承父技能）**：`数据性质=推算` 或 `口径类型∈{测算,弱溯源}` 或 `数值类型≠水平值` 的城市数据点，可信度强制 D 级、禁入 B 级，且与实测分栏。

## 二、城市指标口径字典（防跨家族相加 · 城市版沿用）

> 城市行的「指标口径类型」**必须**取自父技能《口径字典》第七节统一指标口径字典（旅游总花费 / 铁路客运量 / 公路人员流动量 / 酒店RevPAR / 酒店间夜 / 商务部社零 / 平台GMV / 客流人次 / 搜索量 / 播放量 / 支付清算额 / 离岛免税 …）。跨家族指标分列不可相加，城市维度同样适用。

城市维度常见陷阱补充：

| 城市指标 | 说明 | 不可与…相加 |
| --- | --- | --- |
| 城市接待游客量 | 多地文旅局口径，常含"接待/到访"宽口径 | 全国"出游总花费"对应的"出游人次"（边界不同） |
| 城市旅游总收入 | 市文旅局披露，常含本地消费折算 | 全国旅游总花费（避免双层加总） |
| 城市重点景区接待量 | 文博/景区口径，不含全域 | 城市接待游客量（子集，勿叠加） |
| 商圈客流 | 商务局/支付口径 | 任何消费金额（单列） |

## 三、城市人均 / 酒店 / 景区（沿用父技能并落地到城市）

### 3.1 城市人均消费口径
- per-trip：唯一合法称「人均消费」，单位「元/人次」。
- per-day：必须改名「人均每日消费」，单位「元/人天」，永久标 `数据性质=推算` 且等级 D。
- 城市间人均对比须同口径（同 per-trip 或同 per-day），跨口径对比标"不可比"。

### 3.2 城市酒店口径
- 分城市 RevPAR/ADR/OCC 三件套必填（缺失标"本期该城市无权威来源"）；平台 C 级城市增速标"该平台自身口径"；城市档次（奢华/高端/中端/经济）为固定采集项。

### 3.3 城市景区口径
- 城市热门景区二消结构必采；城市文博/演艺独立细分；城市"客流增速 vs 二消增速"背离须单列悖论分析（如某城市"旺丁不旺财"）。

### 3.4 县域（下沉市场）口径
- 县域数据单独层级（`城市层级=县域`），与地级市及以上分列；"奔县"新消费须标注县域口径，不得与城市核心区直接相加。

## 四、城市纵向与排名可比性

- **跨年城市排名漂移**：城市统计口径（如纳入的区县、是否含过境客）每年可能变化，排名对比前须核对「口径版本」一致；不一致时排名标"口径不可比"，仅呈现当年排名。
- **区域结构**：华东/西南等区域占比跨年比较须基于同口径城市集合；新纳入/退出城市须注明，避免区域占比凭空跳变。
- **预测入账（城市版）**：城市级前瞻预测同样进预测台账（`数据性质=预计` + `缺口标记=预判待回填` + `预测ID=[年度][节假日]-CITY-[城市]-F0X`），下期回填核验，闭环到城市维度。

## 五、修订状态与采集时点对齐

> 全国 SSOT 是**可变真相**：源方会回溯修订，且全国与城市的采集时点可能不同——两者都会让勾稽闭合失真。

### 第五节要点

- **修订状态字段（字段 30）**：同时绑定本城行与其 `关联全国指标`。若所引全国指标 `修订状态=已回溯修订`，勾稽表须注明"全国基准已于 [日期] 回溯修订，本期勾稽基于修订后值"并重验闭合/倍数。
- **全国 SSOT 被视为可变真相**：每次采集须记录其 `修订状态`，不得默认"历史全国值永不改"。
- **采集时点对齐**：残差可能混入"全国与城市采集时点不同"的时点差，而非纯未披露；偏差 > 30 天须标注「含时点差，非纯未披露」。
- **较2019 恒定基期**：距今年限 > 5 年须附结构断裂提示，不与同比并列解读。

### 5.1 修订状态字段（字段 30）

| 取值 | 含义 |
| --- | --- |
| `初值` | 初步核算 / 快报（非最终） |
| `终值` | 最终公报 / 核定值 |
| `已回溯修订` | 源方基准修订，总量已变（如文旅部换基期重算） |
| `未标注` | 未声明（默认） |

- 城市行与所引全国行 `修订状态` 联动：全国指标为 `已回溯修订` 时，城市占比/倍数须基于修订后全国值重算；勾稽总表加注修订说明。

### 5.2 修订台账（闭环纵向）

- 凡全国或城市指标发生 `初值→终值` 或 `已回溯修订`，在 SSOT 以行/备注记录：`修订前值`、`修订后值`、`修订方向`、`修订日期`、`对勾稽影响`（闭合变化 / 倍数变化）。
- 报告「口径与数据质量声明」节须列示本期发现的修订及其对勾稽结论的影响；预测台账（父技能第六节）与修订台账分开，互不替代。

### 5.3 采集时点对齐

- 残差 = 全国 − Σ城市 可能混入"全国与城市采集时点不同"的时点差，而非纯未披露。
- 规则：城市行 `采集日期` 与所引全国行 `采集日期` 相差 > 30 天时，残差须标注「含时点差，非纯未披露」，D 级测算。
- 全国总量优先采用与城市同口径发布时点的版本；若不可得，显式声明时点差（不静默并入"未披露"）。

### 5.4 较2019 恒定基期年限提示

- `较2019` 在 2026 已距疫前 **7 年**，消费结构/出行方式经疫情结构性断裂，可比性显著衰减。
- 规则：使用 `较2019` 基期时，报告须附「距今年限 > 5 年，疫后结构已变，仅作长期参考，不与 `同比` 并列解读」提示，或改用滚动三年均。
