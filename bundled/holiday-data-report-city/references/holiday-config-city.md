## 三、城市披露覆盖率预期（按节假日）

| 节假日 | 城市披露特征 | 覆盖率预期 | 备注 |
| --- | --- | --- | --- |
| 春节 | 返乡+出游双峰，县域数据活跃 | 头部城市 60–80% | 县域"返乡消费"口径特殊 |
| 五一 | 城市出游集中，披露充分 | 70–90% | 平台城市榜丰富 |
| 暑期 | 亲子游，海滨/避暑城市突出 | 60–80% | 西南/华南城市拉动明显 |
| 十一 | 全国出游峰值，城市披露最全 | 75–90% | 最适合做城市排名 |
| 端午/中秋 | 短假，城市披露较少 | 40–60% | 城市叙事宜降级"局部样本" |

> 覆盖率 = Σ已披露城市同口径值 ÷ 全国总量。覆盖率 < 40% 的指标，城市排名叙事必须标"局部样本，非全域排名"（见口径字典 0.2 铁律 4）。

## 四、城市检索关键词矩阵（阶段一 · 喂给 fetch）

> 在父技能 / fetch 检索词（`holiday-keywords.md`）基础上，追加城市维度组合，**合并后作为 fetch F1 检索矩阵的输入**；采集由 fetch 执行，本技能不自行检索。开放检索，禁止预置具体业态。

| 维度 | 检索词模板 |
| --- | --- |
| 城市总量 | `[年度][节假日][城市]出游人次/接待游客/旅游总收入/文旅消费` |
| 城市景区 | `[年度][节假日][城市]重点景区接待量/文博接待/演艺票房` |
| 城市酒店 | `[年度][节假日][城市]酒店RevPAR/入住率/平均房价` |
| 城市交通 | `[年度][节假日][城市]铁路发送/机场旅客/地铁客流` |
| 城市平台榜 | `[年度][节假日]携程城市旅游消费榜/[城市]美团到店/同程城市热度` |
| 县域下沉 | `[年度][节假日]县域旅游/奔县/县域消费` |

> **旧闻剔除**：城市数据同样核对发布时间，非目标年度/节假日口径不入库；城市统计公报常滞后，须在「采集日期」注明最新可用源日期。
